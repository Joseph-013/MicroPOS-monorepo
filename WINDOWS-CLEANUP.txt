REMOVING THE OLD MICROPOS (1.0.0) FROM WINDOWS
==============================================

Double-click remove-old-micropos.cmd (next to this file), as the Windows user
who used the old MicroPOS. It runs remove-old-micropos.ps1, which explains
each step as it goes; see the top of that file for its options (-WhatIf to
see what it would do without changing anything).

Do this before installing the new MicroPOS.
